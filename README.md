### Yuemu

Emulator to run programs written for my fictional CPU architecture. See the [YuASM assembler](https://github.com/yusacetin/yuasm) to write programs. Yuemu shows the memory map between addresses specified in the `print_memory` function (from 0x8000 to the end of memory by default) that were modified by the program after execution ends.
